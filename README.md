## 📋 About

Fully custom **luxury wine e-commerce landing page** built for a real winery client. The project focuses on premium visual storytelling, conversion-optimized UX, and a dark luxury aesthetic that reflects the brand identity of a Mexican artisan wine producer.

> 🔗 **Live Demo:** [myalexverse.github.io/raiz-de-plata-website](https://myalexverse.github.io/raiz-de-plata-website/)

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔞 **Age Gate** | Legal age verification modal with frosted glass (glassmorphism) backdrop effect |
| 🍷 **Product Catalog** | Filterable wine grid (Blancos, Rosados, Tintos, Dulces) with hover animations |
| 📋 **Product Detail Modal** | Compact luxury detail cards with tasting notes, food pairing, specs & price |
| 🛒 **Add to Cart** | Cart sidebar with WhatsApp checkout integration |
| 🎨 **Glassmorphism UI** | Hardware-accelerated frosted glass overlays on modals and overlays |
| 📱 **Fully Responsive** | Optimized for desktop, tablet and mobile viewports |
| 🎬 **Scroll Animations** | IntersectionObserver-based reveal animations on scroll |
| ♿ **Accessible** | ARIA roles, keyboard navigation, semantic HTML5 |
| ⚡ **Performance** | Lazy loading images, GPU-accelerated CSS, zero framework dependencies |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup, Open Graph meta, accessibility attributes
- **CSS3** — Custom properties, CSS Grid, Flexbox, `backdrop-filter`, keyframe animations
- **Vanilla JavaScript** — ES6+, IntersectionObserver, smooth scroll, DOM manipulation
- **Zero Dependencies** — No frameworks, no build tools, no npm packages

## 🚀 Getting Started

No build step needed — just open `index.html` in a browser:

```bash
# Clone the repository
git clone https://github.com/myalexverse/raiz-de-plata-website.git

# Open in browser
open raiz-de-plata-website/index.html
```

Or use a local server for the best experience:

```bash
cd raiz-de-plata-website
python3 -m http.server 8000
# Visit http://localhost:8000
```

## 🎯 Design Decisions

- **Dark Luxury Palette** — Deep blacks (#0a0a0a), warm golds (#c5a059), and subtle textures to evoke a premium wine cellar atmosphere
- **No Framework** — Intentionally built without React/Vue/etc. to demonstrate deep understanding of vanilla HTML/CSS/JS fundamentals
- **Mobile-First Responsive** — Breakpoints at 480px, 768px, 992px, and 1200px
- **Conversion-Focused** — Every section guides the user toward purchase via WhatsApp or direct checkout
